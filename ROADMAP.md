# Development roadmap

## Implemented

- Directed citation graphs, provenance and bounded citation paths.
- Cora classification benchmark with four model comparisons and 12 metrics.
- Validation-based configuration selection, split sensitivity and browser dashboard.
- Automated metric, report integrity and dashboard regression tests.

## Future work

- Independent inductive evaluation on a separate citation dataset.
- Comparisons with trained graph neural networks under matched data splits.
- Calibration improvement and broader class-specific error analysis.
- Evaluation of controlled-text extraction against an annotated relation corpus.
