Experimental protocol

  • Transductive subject classification on LINQS Cora; full graph and unlabeled features are available. The primary test split has been reused during development.
  • Stratified development, validation and held-out test partitions; test labels excluded from model selection and label propagation.
  • Compare text-only, one-hop, multi-hop and kernel/diffusion models on the same test nodes.
  • Evaluate 12 scalar metrics, class-level diagnostics, confusion matrices and paired outcomes.
  • Additional overlapping sensitivity splits apply to the first three models only; these are not independent external validation.
