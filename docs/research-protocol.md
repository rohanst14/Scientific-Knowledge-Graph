# Citation network evaluation

The default credential-free benchmark uses the public LINQS Cora dataset (https://linqs.org/datasets/). Download the original Cora content and citation files from the PyGCN mirror (https://github.com/tkipf/pygcn/tree/master/data/cora); record SHA-256 of the content bytes, a newline separator and citation bytes. Preserve original paper identifiers and citation provenance. Validate node and input edge counts and compare the constructed directed graph to the input edge set. Compare logistic regression on bag-of-words features against logistic regression on original plus normalized one-hop neighborhood features. Stratified 70/30 node split, seed 42; both models use the same labels and split. Full graph topology and unlabeled features are available (transductive setting), but test labels are not used for fitting. Report accuracy and macro-F1 without asserting superiority in advance. Cora is historical and not representative of all scientific fields. OpenAlex remains an optional ingestion path; current API access requires credentials, or use a local JSONL snapshot. Citation does not imply causality or endorsement.

## Multi-hop representation and sensitivity analysis

Row-normalized adjacency includes self-loops; concatenate L2-normalized text and propagated representations at depths 0–4. Select depth and logistic regularization from 20 configurations using macro-F1 on a 20% development subset of the training nodes. Refit the chosen model on the full training partition. Retain the seed-42 test split for comparison with text-only and one-hop baselines. Three additional stratified seeds (17, 29, 73) assess sensitivity with the fixed configuration selected on seed 42; the splits overlap, so reported standard deviations are descriptive, not independent confidence intervals or external validation. All topology and unlabeled node features are available in this transductive setting.

## Comprehensive classification evaluation

Evaluate all three models on identical held-out nodes. Probability columns follow the sorted estimator classes. Accuracy, macro precision, balanced accuracy (macro recall), macro-F1 and support-weighted F1 summarize hard predictions; undefined class precision is set to zero. MCC and Cohen's kappa range from -1 to 1, with larger values preferred. Macro ROC-AUC and macro average precision use one-vs-rest binary indicators with equal class weights. Log loss uses natural logarithms; multiclass Brier is mean summed squared error over all class probabilities (range 0–2). Top-label ECE uses 15 equally spaced confidence bins, weighted by bin population. These three probability-quality measures are lower-is-better. Report class support, confusion matrices (true rows, predicted columns), reliability bins and paired correctness counts for the multi-hop model against both baselines. Paired differences are descriptive: connected graph nodes are dependent, so an independent-sample significance claim is not justified. Do not select models using these test metrics. The seed-42 results are comparisons against the implemented baselines, not a claim of state of the art.
