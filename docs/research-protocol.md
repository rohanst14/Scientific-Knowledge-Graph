# Scientific citation network study

OpenAlex metadata is CC0: https://registry.opendata.aws/openalex/ . Use a bounded API sample (default 300 search results) or a local JSONL snapshot containing id, title, publication_year and referenced_works. An API key may be required under current service rules; the local snapshot path requires none. Record query, retrieval date and SHA-256. Citation edges are directed from citing to cited work, with the citing record as provenance. Deduplicate repeated references, exclude self-loops, distinguish external stub nodes from observed records, and compute PageRank on the observed induced graph. A citation is not evidence of causation or endorsement. Search ranking and sample truncation bias the graph. Unit fixtures validate graph construction, not the completeness of OpenAlex. No real-data result is asserted before an experiment executes.
