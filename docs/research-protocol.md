# Citation network evaluation

The default credential-free benchmark uses the public LINQS Cora dataset (https://linqs.org/datasets/). Download the archive at runtime; record its SHA-256. Preserve original paper identifiers and citation provenance. Validate node and input edge counts and compare the constructed directed graph to the input edge set. Compare logistic regression on bag-of-words features against logistic regression on original plus normalized one-hop neighborhood features. Stratified 70/30 node split, seed 42; both models use the same labels and split. Full graph topology and unlabeled features are available (transductive setting), but test labels are not used for fitting. Report accuracy and macro-F1 without asserting superiority in advance. Cora is historical and not representative of all scientific fields. OpenAlex remains an optional ingestion path; current API access requires credentials, or use a local JSONL snapshot. Citation does not imply causality or endorsement.
